# 🥘 Buscador de Receitas

Este é um projeto simples e funcional de buscador de receitas, desenvolvido com **HTML, CSS e JavaScript, que consome a [API pública TheMealDB](https://www.themealdb.com/api.php) para buscar receitas por ingrediente e exibir seus detalhes na tela.

## 🔍 Funcionalidades

- **Busca por ingrediente:** digite um ingrediente (como `chicken`, `rice`, `tomato`) e veja uma lista de receitas relacionadas.
- **Exibição dinâmica de resultados:** as receitas são renderizadas dinamicamente na tela com imagem e nome.
- **Detalhes da receita:** ao clicar em uma receita, os detalhes completos com os ingredientes e medidas são exibidos.
- **Layout responsivo:** interface adaptável a diferentes tamanhos de tela.
- **Imagem de fundo responsiva:** fundo com imagem full screen que se ajusta ao crescimento do conteúdo.

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (ES6)
- [TheMealDB API](https://www.themealdb.com/api.php)
